## 📄 Sobre o Projeto

Projeto desenvolvido para a disciplina de **Engenharia de Software**, ministrada pela Professora Dr. Thaís Alves Burity Rocha, da **Universidade Federal do Agreste de Pernambuco (UFAPE)**.

O **SGAC** tem como objetivo auxiliar os estudantes da UFAPE no gerenciamento das Atividades Complementares Curriculares (ACC) e das Atividades Curriculares de Extensão (ACEX). 

A plataforma automatiza e simplifica o acompanhamento acadêmico, permitindo:
- Armazenamento seguro de certificados digitais.
- Auditoria inteligente integrada com IA (RAG / Groq / Hugging Face).
- Controle de carga horária por categoria e natureza (ACC/ACEX).
- Emissão de relatórios e extratos para formalização institucional.
- Notificações em tempo real sobre o status das solicitações e pendências.

---

## 🎯 Objetivos Funcionais

O sistema atende a três papéis distintos (RBAC):
- **Estudantes:** Cadastro, upload de certificados com extração assistida por IA, acompanhamento de progresso de horas e submissão de relatórios para validação.
- **Avaliadores/Docentes:** Gestão da fila de submissões, homologação, rejeição ou apontamento de pendências com emissão de pareceres circunstanciados.
- **Administradores:** Gestão de usuários institucionais e parametrização dinâmica de cursos e matrizes curriculares.

## 🛠️ Tecnologias Utilizadas

### Front-end
- Angular (Standalone Components / Signals)
- TypeScript
- Tailwind CSS

### Back-end
- Java 21
- Spring Boot 3
- Spring Security (JWT Stateless & Token Blacklist)
- Hibernate / JPA / ArchUnit

### Inteligência Artificial & Busca Semântica
- Integração com API Groq (LLM Qwen)
- Hugging Face API (Embeddings Sentence-Transformers `all-MiniLM-L6-v2`)

### Banco de Dados
- H2 Database (Desenvolvimento / Testes)
- PostgreSQL (Produção)

### DevOps & Qualidade
- Git & GitHub Actions (CI/CD)
- SonarCloud (Análise Estática de Código e Cobertura)
- Render (Plataforma de Hospedagem)
